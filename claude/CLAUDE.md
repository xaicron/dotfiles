# CLAUDE.md (global)

すべてのプロジェクトに共通する指示。プロジェクト固有のルールは各リポジトリの CLAUDE.md / AGENTS.md を優先する。

## 言語

- IMPORTANT: ユーザーへの応答・説明・質問・計画・作業報告は、常に日本語で書く。ユーザーが英語で話しかけた場合も同様。
- 技術用語、コマンド、識別子、エラーメッセージは無理に訳さず原文のまま使う。
- コード中のコメント、コミットメッセージ、PR の本文はそのリポジトリの既存の言語に合わせる。判断できない場合は日本語で書く。

## 作業の進め方

- 変更する前に関連するコードと既存の慣習（命名、構成、テストの書き方）を読み、それに合わせる。
- 依頼された範囲だけを変更する。ついでのリファクタリングや機能追加はせず、気づいた点は提案として伝える。
- 要件が曖昧で結果が大きく変わる場合は、推測で進めずに確認する。些細な判断は妥当なデフォルトで進め、その旨を報告する。
- 変更後はプロジェクトのテスト・lint・ビルドを実行して確認する。実行できなかった・失敗した場合はそのまま報告する。
- 新しい依存関係は必要性がはっきりしている場合だけ追加する。

## Git

- コミットや push はユーザーに頼まれたときだけ行う。デフォルトブランチ上ならブランチを切ってからコミットする。
- コミットは論理的な単位に分ける。
- `.env` や認証情報などの秘密情報はコミットしない。
- force push、`reset --hard`、ブランチ削除など取り消しにくい操作は、事前に確認する。
